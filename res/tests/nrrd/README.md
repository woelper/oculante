These NRRD files are from the tests of pynrrd,
https://github.com/mhe/pynrrd/tree/master/nrrd/tests/data

- BallBinary30x30x30.nrrd: 3D, 16 bit, raw encoding
- BallBinary30x30x30_gz.nrrd: the same, gzip encoding
- BallBinary30x30x30_bz2.nrrd: the same, bzip2 encoding
- BallBinary30x30x30.nhdr: the same, header only, the data is in
  BallBinary30x30x30.raw
- test2d_ascii.nrrd: 2D, 16 bit, ASCII encoding
